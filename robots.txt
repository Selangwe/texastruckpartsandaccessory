# ==========================================================================
# TEXAS TRUCK PARTS — PRE-LAUNCH
#
# This site is not ready to be indexed. It runs on a temporary
# *.vercel.app host, and index.html publishes LocalBusiness structured data
# whose street address has not yet been verified against the Google Business
# Profile. Getting indexed in that state means ranking signals land on a host
# that will be abandoned, with a business address that may be wrong.
#
# Crawling is deliberately ALLOWED below. The block is done with an
# "X-Robots-Tag: noindex" response header set in vercel.json instead.
# That distinction matters: "Disallow: /" stops crawlers from FETCHING pages,
# which also stops them reading the noindex header — so a URL someone links to
# can still end up indexed, as a bare title with no description, and it becomes
# harder to remove. Allowing the crawl and serving noindex is what actually
# keeps pages out of the index.
#
# ---- AT LAUNCH, DO ALL THREE ----
#   1. Point the custom domain at this project
#   2. Set TTP.SITE in assets/config.js to that domain (canonicals, og:url and
#      JSON-LD @id all derive from it and currently fall back to the origin)
#   3. Verify the street address, then REMOVE the X-Robots-Tag block from
#      vercel.json and replace this file with a normal robots.txt + sitemap
# ==========================================================================

User-agent: *
Allow: /
