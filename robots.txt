# The site is open to indexing. Pages carry their own robots meta tag, which
# is where per-page intent lives: index,follow on the homepage, category and
# product templates, noindex,nofollow on the cart.
#
# Nothing is blocked with Disallow that we want kept OUT of the index, and
# that is deliberate. Disallow stops a crawler FETCHING a page, which also
# stops it reading that page's noindex — so a URL someone links to can still
# be indexed as a bare title with no description, and is then harder to get
# removed. To keep a page out of the index, let it be crawled and serve it
# noindex. The cart is handled exactly that way.
#
# Still outstanding: no sitemap is published yet. Add one and reference it
# here with a Sitemap: line once it exists.
# ==========================================================================
