Why V2 — Gap Analysis

Foundation

Based on the live scrape of texastruckparts.shop, the current site runs on a base WooCommerce/WordPress install with minimal customization. Here's what V2 needs to fix to compete at a production level:

⚠️ Critical Gaps

  • No vehicle fitment filter (year/make/model)
  • No structured product data (missing schema markup)
  • No customer review/trust signals
  • No saved searches or wishlists
  • Financing buried — not front-and-center
  • No comparison tool across similar SKUs
  • Missing photo galleries (multi-angle, detail shots)
  • No live inventory counter ("Only 1 left!")

📈 Conversion Opportunities

  • OEM provenance story untold (low-mileage fleet history)
  • No upsell / related parts logic
  • No abandoned cart recovery
  • No local pickup option (Sugar Land, TX)
  • Shipping ETA not shown on product page
  • No "Request a part" form for unlisted inventory
  • No loyalty / repeat buyer incentive

🔍 SEO Gaps

  • Generic meta titles / descriptions
  • No breadcrumb schema
  • No LocalBusiness or Product schema
  • Thin category page content
  • No blog/content hub to capture long-tail searches
  • Image alt text missing or generic
  • Slow page load (unoptimized WP stack)

Tech Stack Recommendation

Technical

Two viable paths depending on budget and in-house dev capacity. The Recommended path gives the best performance and long-term control. The Pragmatic path gets V2 live fastest on an existing comfort zone.

🚀 Recommended Stack (Best Performance)

Ideal for 1,000+ SKUs, speed-first UX, and maximum SEO control.

Next.js 14 (App Router) Medusa.js (Headless Commerce) PostgreSQL Vercel (CDN/Hosting) Stripe + Snap Finance Algolia (Search) Cloudinary (Image CDN) Klaviyo (Email)
Sub-1s page loads
Instant search with filters
Full control over product schema
API-first — easy to extend

⚡ Pragmatic Stack (Fastest to Launch)

Stay on WordPress but modernize with a premium WooCommerce build.

WordPress + WooCommerce Flatsome or Blocksy Theme WP Rocket (Cache) FiboSearch Pro YITH Wishlist WP VIN Lookup (Fitment) Cloudflare CDN FluentCRM (Email)
2–3 week launch timeline
Familiar admin for client
Lower dev cost upfront
Large plugin ecosystem
Key non-negotiable on both stacks: Vehicle fitment lookup (Year → Make → Model) is the #1 trust-builder for truck part buyers. Every search and category page should filter by fitment. This is what separates production-level auto parts sites from basic e-commerce stores.

UX & Design Requirements

Design

🎨 Visual Identity

  • Dark / steel color palette (builds trust with truck buyers)
  • Bold red/orange accent — urgency, American truck feel
  • High-contrast product photography on white or dark backgrounds
  • Industrial typography — bold headlines, clean body text
  • No generic stock photos — real OEM parts, real warehouse shots

📱 Mobile-First Design

  • Thumb-friendly filter panel (bottom drawer on mobile)
  • Swipeable photo gallery on PDP
  • Sticky "Add to Cart" bar on scroll
  • Click-to-call phone number in header
  • Tap-to-text for quick questions
  • Fast Checkout (Apple Pay / Google Pay)

🛒 Product Detail Page (PDP)

  • 5–8 photos minimum per product (all angles, close-up, installed)
  • Fitment table: which trucks this fits
  • Savings badge: "Save $X vs. dealer" prominently displayed
  • OEM badge + fleet provenance badge
  • Urgency: "Only 1 in stock" + "Ships in 1–2 business days"
  • Financing: "As low as $X/mo" inline near price
  • FAQ accordion for common questions

🔒 Trust Architecture

  • SSL badge + secure checkout in footer/header
  • Google Reviews widget (pull live star rating)
  • BBB Accreditation badge (if applicable)
  • Return policy guarantee badge
  • Financing partner logos (Snap, Acima, Progressive)
  • Real customer photos with reviews
  • Texas address + phone clearly visible

⚙️ Search & Filter

  • YMM (Year/Make/Model) fitment lookup — always accessible
  • Filter: Category, Price Range, Color, In Stock Only
  • Sort: Newest, Price Low–High, Biggest Discount
  • Autocomplete search with product thumbnails
  • Search result count and active filter pills

💳 Checkout UX

  • Progress bar (Cart → Shipping → Payment → Confirm)
  • Guest checkout (no forced account creation)
  • Address autocomplete (Google Places API)
  • Financing option inline at payment step
  • Order confirmation with tracking link
  • SMS opt-in for shipping updates

SEO & Performance

Growth

🏗️ Technical SEO (Day 1)

  • Product schema (name, price, availability, image, review)
  • BreadcrumbList schema on all pages
  • LocalBusiness schema with Sugar Land address + hours
  • Canonical URLs to prevent duplicate content
  • XML sitemap auto-generated and submitted
  • Core Web Vitals: LCP <2.5s, CLS <0.1, FID <100ms
  • Image WebP format + lazy loading

🔑 Target Keyword Strategy

  • "2019-2025 Ram 2500 OEM front bumper" (high intent)
  • "Chevy Silverado factory tailgate take-off" (transactional)
  • "OEM truck parts Sugar Land Texas" (local)
  • "Ram 2500 bumper replacement cost" (informational → blog)
  • "OEM vs aftermarket truck bumper" (top of funnel)
  • "Ram 3500 tail light replacement" (repair intent)

📝 Content SEO (Ongoing)

  • Category pages: 200–400 word intro with target keywords
  • Product names: include year, make, model, color, OEM
  • Blog: 2 posts/month targeting long-tail install + fitment queries
  • FAQ schema on every product and category page
  • Google Business Profile fully optimized with product photos

⚡ Performance Targets

  • PageSpeed Score: 90+ mobile, 95+ desktop
  • TTFB: <200ms (CDN + edge caching)
  • Image CDN: Cloudinary or Imgix for automatic optimization
  • Lazy load below-fold images and components
  • Prefetch adjacent product pages on hover
  • Service worker for offline shell + asset caching

Content & Listings Strategy

Content

Every product listing is a landing page. The current site has thin descriptions. V2 listings should be structured like this for every SKU:

Listing Element Current State V2 Standard
Title Basic product name [Year Range] [Make] [Model] [Part] OEM [Color] [Qualifier] — SEO-optimized, 60–80 chars
Photos 1–2 images 5–8 images: front, rear, side, close-up detail, installed on vehicle, any imperfections called out
Description Short paragraph (already scraped) Structured: Condition → Fitment → Specs → Install notes → Shipping → Financing → FAQ
Fitment Table Missing Table: Year / Make / Model / Trim / Notes (e.g., "with sensor holes", "without tow package")
Savings Callout Regular vs. sale price shown Bold "Save $X vs. dealer MSRP" badge next to price
Reviews None Star rating + 3–5 verified buyer reviews; post-purchase email sequence to collect
Questions / FAQ None 5 common questions per product: fitment, shipping, install time, returns, financing
Content Quick Win: The 80 product descriptions already scraped are a strong foundation. V2 should expand each into a structured template (above) — approximately 400–600 words per PDP. With the existing data + AI-assisted expansion, this is a 2–3 day content production task, not weeks.

Risks & Mitigations

Planning
Risk Severity Mitigation
SEO rankings drop during migration
High
 301 redirect map for every URL; submit new sitemap immediately; monitor Search Console daily for 4 weeks post-launch
Photo library missing for new product pages
High
 Photo shoot all current inventory before launch; minimum 5 photos per SKU; use placeholder "coming soon" for anything un-shot rather than removing the product
Fitment data incomplete at launch
Medium
 Launch YMM filter with best-effort data; flag any incomplete fitment on PDP; add "request fitment verification" contact link
Client unfamiliar with new CMS/admin
Medium
 Record Loom walkthroughs for all admin tasks; create a simple SOPs doc for adding new products and updating inventory
Financing integration delays checkout
Medium
 Launch with Stripe + PayPal as primary payment; add Snap/Acima in Phase 2 (2–4 weeks post-launch) so it doesn't block the release
Low launch traffic / no paid budget
Low
 Facebook Marketplace listings are free and drive immediate traffic; Google Business Profile posts are free; email list is free to send — organic channels first
